# 동네공부방

서울사이버대학교 UI/UX 프로그래밍 실습 프로젝트입니다.
걸어서 갈 수 있는 공부방을 시간 단위로 예약하는 서비스의 소개 페이지를 만듭니다.

## 2주차 · HTML 구조 변경 기록

### 바꾼 구조
1주차의 `h1` + `p` 두 줄짜리 페이지를 `header` / `main` / `footer` 구조로 나눴습니다.
`main` 안에는 서비스 소개, 주요 기능, 이용 방법, 소식 받기를 각각 `section`으로 묶고
`id`를 붙였습니다.

### 변경 이유
- 처음 방문한 사람이 **무엇을 하는 서비스인지 → 무엇을 할 수 있는지 → 어떻게 쓰는지**
  순서로 읽도록 정보 순서를 정했습니다. 이 순서를 `<body>` 첫 줄 주석에 먼저 적고
  그대로 `section` 순서로 옮겼습니다.
- 주요 기능은 순서를 바꿔도 의미가 그대로라서 `ul`, 이용 방법은 순서를 지켜야 해서 `ol`로
  구분했습니다.
- `nav`의 `href`와 각 `section`의 `id`를 연결해 긴 페이지에서 필요한 영역으로 바로
  이동할 수 있게 했습니다.
- 이미지 `alt`에는 파일명이 아니라 "공부방 책상에 앉아 노트북으로 공부하는 사람"처럼
  그 자리에서 이미지가 전달하는 내용을 적었습니다.
- `label`의 `for`와 `input`의 `id`를 `email`로 맞춰, 라벨을 눌러도 입력칸이 선택되게 했습니다.

## 3주차 · CSS 수정 기록

### 수정한 내용
주요 기능 목록인 `.feature-list`에 `display: flex`와 `gap: 20px`을 적용하고,
각 `.feature-card`에 `flex: 1`과 배경색·테두리를 넣었습니다.

### 화면 변화
세로로 길게 나열되던 세 기능이 같은 너비의 카드로 한 줄에 배치되고,
카드 사이 간격이 일정해졌습니다.

### 사용자 이점
세 기능이 같은 종류의 정보라는 것이 한눈에 보여서
어떤 기능이 있는지 서로 비교하며 읽기 쉬워졌습니다.
